## Overview

asterwise-typescript is the official TypeScript/JavaScript SDK for the Asterwise Vedic
Astrology HTTP API. Generated client code uses **@hey-api/openapi-ts** (file banners:
`This file is auto-generated by @hey-api/openapi-ts`). Runtime dependency:
**@hey-api/client-fetch** (^0.9.0). The npm distribution name is **`asterwise`**
(`npm install asterwise`). Build: **TypeScript** (`tsc`) plus post-build **`fix-esm.mjs`**
(rewrites relative imports in `dist/` to include `.js` extensions). Package **`type`**
is **`module`** (ESM). npm registry **`asterwise`** returns HTTP **200** with latest
published version **0.1.4** (checked 2026-05-21). Package names **`@asterwise/sdk`**,
**`asterwise-sdk`**, **`asterwise-typescript`** return HTTP **404** on npm. Role in the
platform: developer-facing SDK; README references **docs.asterwise.com** for API reference.
